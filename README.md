## RU / Русский

Бесплатный VPN-клиент для Android. Панель и токен уже зашиты — установка и подключение без настроек.

**Установка (Android 12–16):**
1. Скачайте APK из [Releases](https://github.com/pmvmoscow777-cpu/jupiter-vpn/releases/latest).
2. Откройте файл (шторка уведомлений или приложение «Файлы»).
3. Android предупредит о неизвестном источнике → **Настройки** → **Разрешить из этого источника**.
4. Вернитесь → **Установить**.
5. Откройте Jupiter VPN, выберите страну, нажмите подключить. При первом подключении разрешите VPN (**ОК**).
6. На Android 13+ разрешите уведомления, чтобы видеть статус.

Если Play Protect предупреждает — **Подробнее → Всё равно установить**.

## EN / English

Free Android VPN client. Panel and token are built in — no setup needed.

**Install (Android 12–16):**
1. Download the APK from [Releases](https://github.com/pmvmoscow777-cpu/jupiter-vpn/releases/latest).
2. Open the file (notification shade or your **Files** app).
3. Android warns about unknown sources → **Settings** → **Allow from this source**.
4. Go back → **Install**.
5. Open Jupiter VPN, pick a country, tap connect. Allow the VPN connection on first use (**OK**).
6. On Android 13+ allow notifications to see connection status.

If Play Protect warns — **More details → Install anyway**.
